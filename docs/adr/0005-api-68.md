# ADR 0005: API version 68.0 everywhere

- Status: Accepted
- Date: 2026-10-28

## Context

Agent metadata changed shape at API 68.0, and mixed API versions across orgs block agent deployments.

## Decision

Pin `sourceApiVersion`, CLI `org-api-version` and every `-meta.xml` to 68.0.

## Consequences

All orgs must be on the 68.0 release before a deployment. New files must use 68.0, and reviewers check this.
